# The Honey Bear Honeypot

This project is a SSH honeypot, used to both capture data from SSH attackers in a realistic but simulated shell environment, and to provide fun entertaining tasks for users who are are aware of the honeypot and want to play with it. The project also includes a GUI that draws a bear's face as a joke and fun addition to the project to show new messages, count the number of users, and to interact with the data coming from the honeypot.

## Project Structure

- `/internal`: Contains the golang source code for all internal packages.
- `/internal/config`: The config package that reads the config file or any url params.
- `/internal/db`: The database layer, using SQLite to store data.
- `/internal/entity`: A simple orm of sorts over the top of the database layer.
- `/internal/gui`: The GUI package that creates a crossplatform GUI using Fyne. This displays the bear face, shows the nofications, user counts, and handles all UX state and click/touch events.
- `/internal/honeypot`: The package that handles all of the SSH honeypot logic, including the server itself, SSH tunneling, the fake shell enviroment, built in with and bubbletea libraries, including the fake directory structure.
- `/misc/design`: Design files. Not needed for any code changes. Ignore this directory.
